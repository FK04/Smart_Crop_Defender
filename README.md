# 🌱 Smart Crop Defender
Smart Crop Defender is a machine learning–based application designed to detect plant diseases from leaf images.  
The project aims to support early disease identification to help farmers and researchers take timely action.

---

## 🚀 Features
- Plant disease detection using deep learning
- Trained CNN model saved in `.keras` format
- Image-based prediction workflow
- Simple Python-based implementation
- Ready for integration with a web interface

---

## 🧠 Tech Stack
- Python  
- TensorFlow / Keras  
- NumPy  
- OpenCV  
- Deep Learning (CNN)

## ⚙️ How It Works
1. Dataset images are preprocessed and labeled  <br>
2. A CNN model is trained using Keras  <br>
3. The trained model is saved for reuse  <br>
4. New plant images are tested for disease prediction  <br>
